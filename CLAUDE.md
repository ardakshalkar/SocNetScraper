This repo collects public Threads posts about Narxoz University (нархоз, narxoz).

When asked for Threads mentions, run `python -m socnetscraper scrape` from the repo root, then summarize posts from the last 7 days (and last 24 hours if any). Open `data/index.html` or `python -m socnetscraper view`. If login is required, tell the user to run `python -m socnetscraper login` first. Do not build a second scraper.
